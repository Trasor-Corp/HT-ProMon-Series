## QR-code distribution

The manual is distributed through QR codes. Keep the current documents in the top-level folder and preserve their filenames so existing QR-code links continue to point to the current revision.

When publishing an updated document:

1. Archive the outgoing revision in [`Previous Revisions`](Previous%20Revisions/), including its revision number in the archived filename.
2. Replace the top-level document with the updated revision using the same filename.
3. Verify that the existing QR-code link opens the updated document after publication.

## Previous revisions

Older documents are stored in [`Previous Revisions`](Previous%20Revisions/) for historical reference. Use the top-level documents for the most current information.
